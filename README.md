# X1SCore

**One framework. Built for roleplay.**

X1SCore is an open-source roleplay framework designed to provide a powerful, modular foundation for building immersive FiveM communities.

Inspired by the ideas and architecture of modern roleplay frameworks, X1SCore is built as its own independent ecosystem — giving developers the freedom to create, extend, and customize their servers without being locked into a single approach.

The framework provides the core infrastructure developers need to build roleplay experiences, while allowing server owners and developers to shape the gameplay, systems, and experiences on top of it.

---

## 🧭 One Framework, Endless Possibilities

X1SCore is designed around a simple philosophy:

> **Build the foundation. Let the community build the experience.**

The framework handles the underlying systems that roleplay resources depend on while keeping the development experience flexible and approachable.

X1SCore is built with modularity in mind, allowing individual systems to be developed, replaced, expanded, or customized without requiring the entire framework to be rewritten.

---

## 🌐 X1SCore Ecosystem

The X1SCore ecosystem is built around a collection of interconnected resources and development tools.

### **X1SCore Framework**

The core foundation of the X1SCore ecosystem.

Provides the primary framework functionality that resources can build upon, including framework APIs, player management, callbacks, events, utilities, and shared functionality.

### **X1SCore Resources**

Official resources designed to work alongside the framework.

These resources extend the core functionality of X1SCore and provide commonly needed systems for roleplay servers.

### **X1SCore Developer Tools**

Tools and utilities designed to make developing, debugging, and maintaining X1SCore resources easier.

---

## 🧩 Modular by Design

X1SCore is designed so that developers can build systems independently while still taking advantage of the framework's core functionality.

Resources can interact with X1SCore through its APIs, events, exports, and shared systems.

This allows developers to create:

- 🚓 Police & Law Enforcement Systems
- 🚑 Emergency Services
- 💼 Jobs & Businesses
- 💰 Economy Systems
- 👤 Character & Player Systems
- 🚗 Vehicle Systems
- 🏠 Housing Systems
- 📦 Inventory Systems
- 📱 Communication Systems
- 📋 MDT & CAD Systems
- 🎯 Mission & Activity Systems
- 🔧 Custom Server Resources

And much more.

---

## ⚡ Developer First

X1SCore is built with developers in mind.

The goal is to provide a framework that is:

- **Modular** — Build systems independently.
- **Extensible** — Expand the framework through resources and APIs.
- **Accessible** — Keep development approachable.
- **Optimized** — Minimize unnecessary resource overhead.
- **Maintainable** — Keep systems organized and understandable.
- **Community Driven** — Build alongside the people using it.

Developers should be able to understand how X1SCore works, build on top of it, and create their own systems without fighting the framework.

---

## 🛠️ Built for FiveM

X1SCore is primarily designed for the **FiveM** ecosystem.

The framework takes advantage of FiveM's native capabilities while providing an organized foundation for creating complex roleplay experiences.

X1SCore resources are designed to communicate through clearly defined framework interfaces, allowing individual systems to remain independent wherever possible.
